First sign-in

The editor saves directly to this website’s GitHub repository. You only need to set up access once per browser.

  1. Open GitHub’s fine-grained access token page.
  2. Under Repository access, choose Only select repositories and select suhaancoding.github.io.
  3. Under Repository permissions, set Contents to Read and write. No other write permissions are needed. Choose an expiration you’re comfortable with.
  4. Generate the token yourself. Copy it, open the editor, choose Sign in using access token, and paste it there. Do not paste it into chat.

The editor remembers the sign-in in this browser until you sign out or the token expires. You can revoke it in GitHub settings at any time.

Writing and publishing

Use Notes to create, edit, duplicate, publish, or remove a note. New notes start as drafts. Turn Draft off when you want one to appear publicly. Draft files saved to GitHub remain visible in the public repository.

The Insert menu adds equations, tables, code blocks, and images. Formatting and equation previews update immediately. A save goes to GitHub, and the public site updates after its publish job finishes, usually within a minute or two.

Under Website, edit your name, profile line, image, links, experience, and section labels. Layout and styles stay fixed.

Use sections, tags, pins, and order to organize notes. You can return to plain Markdown mode at any time.
