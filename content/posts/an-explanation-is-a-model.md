This is an example note, not a published piece by Suhaan.

A useful explanation is a small model you can run in your head. It should help you predict what happens when something changes.

One way to test your understanding: change a single assumption. Can you predict the result before looking it up?

If you can repeat the definition but cannot make a prediction, there is probably another layer to understand.
